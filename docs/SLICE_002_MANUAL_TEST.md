## 0. 前置：开启微信开发者工具服务端口（一次性）

CLI 自动化（`npm run wechat:*`）依赖服务端口。首次需要手动开启一次：

1. 打开微信开发者工具。
2. 菜单「设置」→「安全设置」（或点右下角「设置」）。
3. 找到「服务端口」开关，**打开**（CLI 调用需要它）。
4. 之后 `npm run wechat:open` / `wechat:preview` / `wechat:islogin` 就能用了。

## 1. 打开项目

```bash
npm run build:wechat   # 重新构建微信版（已包含最新货舱代码）
npm run wechat:open    # 在开发者工具中打开 build/wechatgame
```

或在工具里手动导入：导入 → 选择 `/Users/chenyan/Documents/VibeCoding/WastelandDepot/build/wechatgame`。

工具界面确认：左上角显示「小游戏模式」，模拟器是竖屏 iPhone 12/13 (Pro)。

| # | 操作 | 预期 |

## 4. 调试器里 Errors: 2 / Warnings: 8 怎么判断

工具底部面板显示「调试器 - Errors: 2, Warnings: 8」。这些**很可能是工具/GitLens 扩展自身**的报错，不一定是游戏代码问题。判断方法：

1. 点「调试器」面板 → 看 Console 标签。
2. 如果错误文本里包含 `wechatgame/assets/main/index.js` 或 `PrototypeScene`、`trunk` 等**我们的代码** → 是游戏问题，截图报错反馈。
3. 如果错误是 GitLens、`source`、网络、`miniprogram` 之类 → 与游戏无关，可忽略并记录。
4. 特别关注：是否有 `Uncaught TypeError`、`Cannot read properties of undefined`、`is not a function`。
