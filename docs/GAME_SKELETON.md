# 《末班车：废土仓库》游戏骨架

> 状态：第二版（2026-09-06 GDD 对话定型）。本文描述的是游戏设计目标，不等同于当前已实现功能；当前代码与旧模型的关系见第 15 节。
> 本版取代「十日 × 六地点单线」旧骨架。旧骨架的核心资产（货舱占格、五资源、事件结算框架、横轴卷轴演出）全部保留并复用。

## 1. 一句话定义

玩家选一位带天赋的主角，驾驶与他合为一体的末班车，以仓库为家：外出进入横轴区域场景搜刮物资、必战怪物、结识 NPC；用带回的物资升级仓库与车载武器、制作图纸物品、扩编乘员；每隔一段时间怪物攻家，考验弹药储备；最终修复市中心通信基站、向外界发出求救信号即胜利，全员健康打光即失败重开。

> 一个主角、一辆车、一个仓库、一张区域地图、一条胜利终点线。

## 2. 核心体验

不变的灵魂：**后备箱装不下时，留什么、丢什么。** 在此之上新增四组常态取舍：

- **多带人 vs 多口粮**：乘员是探索收益与攻击的乘数，也是每天 1 食物/人的成本。
- **弹药 vs 生产**：子弹是唯一攻击来源的口粮，物资不能全投升级，守家的子弹永远要留。
- **修车 vs 修人**：耐久归零车趴窝，健康归零人没了，材料和药品各救各的。
- **守工事 vs 出车迎**：守家战的一次性抉择，省弹挨砸还是耗弹护家。

## 3. 核心循环

单次外出目标时长约 3 分钟：

```text
查看仓库状态与地图
        ↓
选择区域出发（消耗燃油；主角天赋影响该区域掉落）
        ↓
横轴区域场景：连续 10 个事件节点
（搜刮点 / NPC 任务 / 随机事件 / 2~3 场必战怪物）
        ↓
在有限储物量中持续取舍
        ↓
返仓结算：物资入库、全员消耗食物、推进一天
        ↓
升级仓库（储量/工作台）、升级车载武器、制作图纸物品
        ↓
每隔 N 天怪物攻家：守工事 or 出车迎（自动结算）
        ↓
收集图纸与零件 → 修复市中心基站 → 求救成功 = 胜利
```

局长为长局（天数不设硬上限，软节奏由波次压力控制，数值见 PENDING）。

## 4. 首版内容边界

| 维度 | 首版规模 |
| --- | --- |
| 地图 | 1 张平面地图：仓库在一角，若干区域（城区 + 郊区），市中心为中心地点 |
| 区域 | 5~6 个可探索区域 + 市中心（默认值，待拍板） |
| 单区域 | 横轴连续 10 个事件节点 |
| 仓库升级 | 2 个维度（储量、工作台） |
| 载具 | 1 辆，属性见第 7 节 |
| 攻击来源 | 车载武器 1 条升级链（9 级） |
| 资源 | 5 种（不变） |
| 乘员 | 主角 + 载客量上限的 NPC（开局 2 个 NPC 位） |
| 胜利 | 1 种（基站激活） |
| 失败 | 1 种（全员健康归零） |
| 随机事件 | 20~30 个 |

## 5. 五种资源

| 资源 | 主要用途 | 形成的压力 |
| --- | --- | --- |
| 燃油 | 到达区域与返程 | 探索半径与安全余量的取舍 |
| 食物 | 全员每人每天 1 | 乘员越多持续成本越高，多带人是投资也是负担 |
| 材料 | 修车、升级仓库与武器 | 当前生存与长期投资的取舍 |
| 药品 | 恢复角色健康度 | 是否为未来风险保留稀缺资源 |
| 弹药 | 车载武器战斗消耗（守家与野外共用） | 不能把物资全投生产——储备量是核心资源控制考验 |

不增加第六种货币；新区域的掉落是**零件与图纸**（喂给升级与制作系统），不是新资源。

## 6. 仓库

只做两个升级维度：

- **储量**：提高资源存储上限。
- **工作台**：解锁更多制作（基站设备、图纸物品），并作为车载武器升级的等级门槛。

仓库另有**耐久**（仅守家战使用，见第 10 节）。治疗伤员用药品、修复车辆用材料，直接消费，不设独立设施。日常消耗全部自动结算，玩家的仓库操作只有：升级、制作、出发前整备——不做每日手动收菜。

## 7. 载具与车载武器

载具属性：**耐久、防护、攻击、储物量、载客量**。防护减少战斗伤害；耐久是战斗伤害的第一层（见第 10 节管道）；储物量即单次收益上限；载客量决定可带 NPC 数（可升级，途径待拍板）。载具升级维度与消耗见 PENDING。

**车载武器是全游戏唯一攻击来源**（无枪械、无角色攻击），一条升级链：

- Lv1~3 车载机枪 → Lv4~6 重机枪 → Lv7~9 火箭巢；每 3 级换名称与外形，攻击力阶梯上升。
- 升级消耗材料 + 特定区域零件；Lv4 需工作台 2 级、Lv7 需工作台 3 级（工作台等级 = 武器上限门槛）。
- 等级越高单发威力越大、单场耗弹越多——威力与弹药经济挂钩。
- 数值表（各级攻击/耗弹/材料）见 PENDING。

## 8. 主角与乘员

**主角**：开局三选一（医生/农场主/工人等，清单待拍板）。每个主角带一个天赋：**去对应区域探索时，该类物资掉落大幅增加**——仅此一项，不做更多系统。主角默认司机、人车合一：永远在车上，占驾驶位，不计入载客量与人数乘数；正常消耗食物、参与健康结算。

**NPC 乘员**：属性人人一致，无职业、无装备栏。每人只有**健康度**（药品恢复）。价值 = 人数：乘员越多，探索物资乘数与车辆攻击乘数越高。招募途径：探索中遇 NPC → 完成其任务（交付要求的物资，换取情报或图纸；一次或多次）→ 可邀请入队。

**健康与收益挂钩**：探索收益倍率按队伍健康度阶梯折扣，满健康满倍率，折扣设地板（默认 0.5）防「越弱越穷越弱」死循环。阶梯表见 PENDING。

## 9. 区域与横轴探索

- 地图为一张平面，几张贴图代表几个区域，仓库在一角，市中心在中央。选中区域，小车移动过去，进入**横轴区域场景**。
- 区域默认**锁定**，通过**情报解锁**（NPC 任务奖励、探索掉落）——地图不是开局明牌，揭示感是长线新鲜感的来源。
- 各区域掉落倾向不同（医院区多药品、工厂区多材料……），缺什么去哪；凑齐升级材料需要探索多个区域。
- 单区域 = 横轴连续 **10 个事件节点**，构成默认：4 个搜刮点 + 1~2 个 NPC + 2~3 个必战怪物 + 余量随机事件，顺序随机。越靠后收益越高、怪物越强（数值待拍板）。**必战不可跳过**——战斗是探索的成本，不是选项。
- **图纸双通道**：深区探索随机掉落 + NPC 任务定向换取。基站设备图纸走同一通道。

## 10. 守家战（波次）

每隔 N 天怪物找上门（间隔与强度曲线见 PENDING）。**波次明牌**：下一波强度提前一天预告，玩家能做预算——没有突然袭击。

统一伤害管道（一条攻击力计算线）：**怪物伤害 → 载具耐久 → 仓库耐久 → 全员健康**。攻击永远来自车载武器。

战前一次二选一（自动结算，无手动战斗）：

- **出车迎击**：伤害先落载具耐久（车挨打护仓库），弹药正常消耗。
- **依托工事**：伤害落仓库耐久（车不损），弹药消耗降低。

**防守失败**（仓库耐久被打穿）：全员健康扣至 20/100、仓库随机丢失一批物资（默认 5~20 件区间，随波强度放大），战斗结束、可修复重来。**全员健康归零 = 本局失败**，重开。

危险度即波强度刻度：随天数与事件推升，决定下一波规模，守家表现反作用于它；爬升至平台值后封顶（休闲玩家可以慢慢修基站，「慢」必须可行）。

## 11. 胜利与失败

- **胜利**：收集齐基站设备图纸 → 工作台制作替换设备 → 修复市中心通信基站 → 求救信号发出。结局：人类抵抗部队获得战斗胜利，并找到了这个还在抵抗的庇护所。
- **失败**：全员健康归零。失败就重开，好好做人，别再当菜鸟。
- 首版单一胜负结局，不做多结局分支。

## 12. 序章与首局教学

控制在约 15 秒内开始操作：三选一选主角（天赋当场展示）→ 车辆自动驶向仓库 → 路上出现若干可拾取物资与一次装不下的取舍 → 抵达仓库，带回内容即开局资源。不制作长过场。

## 13. 广告与付费底线

（不变）广告只能提供额外选择，不能消灭载重和生存取舍。不放横幅、开屏和强制插屏；只允许玩家主动触发的低频激励视频；广告失败不阻断游戏；不用「全物资翻倍」破坏核心规则；不通过提高油耗、制造必死局贩卖解药。首版候选入口仍是无线电侦察与事故紧急救援，核心循环成立后再验证。

## 14. 设计纪律

从 GDD 对话沉淀的硬约束，评审时按此执行：

1. **疲惫下班测试**：任何系统设计完先问「累了一天的人愿意在这步动脑吗」，过不了关再精巧也砍。
2. **决策不超前于信息**：不让玩家在信息不足时做高频决策（迷雾疲劳的教训）；波次明牌、账目可预算。
3. **合成 ≤ 1 跳**：战利品即零件，不做中间品树。
4. **牌面即全部真相**：规则语义写在界面上，不藏在判例里（游戏王的教训）。
5. **单一攻击管道**：攻击来源只有车载武器一条线，不新增平行战斗系统。
6. **新要素先问能否挂在现有五资源上**，挂不上就不做。

## 15. 当前进度与旧模型的关系

六切片（竖屏拖拽/货舱占格/地图卷轴/节点拾取/十日循环/道路事件）已验证的手感资产**全部复用**：货舱拖拽与占格、横轴卷轴演出、事件面板与结算框架、五资源账目。

与旧模型的冲突项，自下阶段起参数化改造：十日循环 → 长局与波次（`GAME_DAYS` 参数化）、六地点单线 → 区域制与解锁、职业数据 → 主角天赋制、幸存者占舱 → 载客量制。存档 schema 将随首个改造切片升级版本。最新进度见 [README.md](../README.md)。

## 16. 停车场：首版明确不做

- PC 版及跨平台界面。
- 开放世界连续大地图、自由走格子驱雾（我们做的是平面区域地图 + 横轴场景入口）。
- 实时战斗、手动回合制、战斗 AI（战斗全部为自动结算）。
- 自由建造、生产链、每日手动收菜。
- 角色装备栏、词条稀有度、技能树、NPC 职业属性差异。
- 多车辆编队、多武器系统。
- 联机、排行榜、社交。
- 物理引擎、3D、骨骼动画、重型粒子。
- 付费系统及广告变现调优。
