# 《末班车：废土仓库》游戏骨架

> 状态：第二版（2026-09-06 GDD 对话定型）。本文描述的是游戏设计目标，不等同于当前已实现功能；当前代码与旧模型的关系见第 15 节。
> 本版取代「十日 × 六地点单线」旧骨架。旧骨架的核心资产（货舱占格、五资源、事件结算框架、横轴卷轴演出）全部保留并复用。

## 1. 一句话定义

玩家选一位带天赋的主角，驾驶与他合为一体的末班车，以仓库为家：外出进入横轴区域场景搜刮物资、遇怪可选战或绕行、结识 NPC；用带回的物资升级仓库与车载武器、制作图纸物品、扩编乘员；每隔一段时间怪物攻家，考验弹药储备；最终修复市中心通信基站、向外界发出求救信号即胜利，全员健康打光即失败重开。

> 一个主角、一辆车、一个仓库、一张区域地图、一条胜利终点线。

## 2. 核心体验

不变的灵魂：**后备箱装不下时，留什么、丢什么。** 在此之上新增四组常态取舍：

- **多带人 vs 多口粮**：乘员是探索收益与攻击的乘数，也是每天 2 食物/人的成本。
- **弹药 vs 生产**：机枪每场大额扣弹、火箭弹按发折算，物资不能全投升级，弹药储备是道持续的算术题。
- **修车 vs 修人**：耐久归零车趴窝，健康归零人没了，材料和药品各救各的。
- **持续 vs 爆发**：机枪弹按场大口消耗，火箭弹按发折算弹药——每场战斗前带几发火箭弹，是道算术题。

## 3. 核心循环

一次外出 = **至少 3 天**（到 1 天 + 探 1 天 + 返 1 天），探索天数玩家自选：

```text
查看仓库状态与地图
        ↓
选择区域出发（消耗燃油；1 天车程；主角天赋影响该区域掉落）
        ↓
横轴区域场景：连续 10 个事件节点
（搜刮点 / NPC 任务 / 随机事件 / 2~3 个怪物关卡）
        ↓
在有限储物量中持续取舍
        ↓
玩家选择：再探一天 或 返程
        ↓
返程（1 天车程）→ 抵仓结算：物资入库、全员消耗食物、天数推进
        ↓
升级仓库（储量/工作台）、升级车载武器、制作图纸物品
        ↓
每 4 次行程怪物攻家：实时守家战（围墙→战车→乘员三层承伤）
        ↓
收集图纸与零件 → 修复市中心基站 → 求救成功 = 胜利
```

局长为长局（天数不设硬上限，软节奏由波次压力控制）。

## 4. 首版内容边界

| 维度 | 首版规模 |
| --- | --- |
| 地图 | 1 张平面大地图：仓库在一角，N 个区域（各分三级子区域），市中心为中心地点 |
| 区域 | 默认 8~10 个区域 × 3 级子区域 + 市中心（数量待拍板，D2） |
| 单区域 | 横轴连续 10 个事件节点 |
| 仓库升级 | 2 个维度（储量、工作台） |
| 载具 | 1 辆，属性见第 7 节 |
| 攻击来源 | 车载武器两件套：机枪（锥形持续）+ 火箭筒（拖放范围） |
| 资源 | 5 种（不变） |
| 乘员 | 主角 + 载客量上限的 NPC（开局 2 个 NPC 位） |
| 胜利 | 1 种（基站激活） |
| 失败 | 1 种（全员健康归零） |
| 随机事件 | 20~30 个 |

## 5. 五种资源

| 资源 | 主要用途 | 形成的压力 |
| --- | --- | --- |
| 燃油 | 到达区域与返程 | 探索半径与安全余量的取舍 |
| 食物 | 全员每人每天 2 | 乘员越多持续成本越高——多带人是投资也是负担，食物流（多招人）的天赋优势由消耗量放大 |
| 材料 | 修车、升级仓库与武器 | 当前生存与长期投资的取舍 |
| 药品 | 恢复角色健康度 | 是否为未来风险保留稀缺资源 |
| 弹药 | 机枪每场固定扣量（随区域等级）、火箭弹按发折算（战斗演出弹数不计账） | 弹药流积极开怪换高掉落，缺弹则绕行放弃收益——储备与消耗都是选择 |

不增加第六种货币；新区域的掉落是**零件与图纸**（喂给升级与制作系统），不是新资源。

## 6. 仓库

只做两个升级维度：

- **储量**：提高资源存储上限。
- **工作台**：解锁更多制作（基站设备、图纸物品），并作为车载武器升级的等级门槛。

仓库另有**耐久**（仅守家战使用，见第 10 节）。治疗伤员用药品、修复车辆用材料，直接消费，不设独立设施。日常消耗全部自动结算，玩家的仓库操作只有：升级、制作、出发前整备——不做每日手动收菜。

**任务板**：在仓库界面交付探索中接下的 NPC 任务（物资换情报/图纸），并可邀请已达成任务的 NPC 入队（见第 8 节）。

**多存档栏**（3 栏）：仅在仓库时可手动存档，探索途中禁止——存档点是玩家自己选的，探索风险回到玩家手里。存档用微信本地存储（容量与实现细节见 D23）。

## 7. 载具与车载武器

载具属性：**耐久、防护、攻击、储物量、载客量**。防护减少战斗伤害；耐久是战斗伤害的承伤层（见第 10 节管道）；储物量即单次收益上限；载客量决定可带 NPC 数（可升级，途径见 PENDING）。

**战斗形态：竖版实时手动操作**（类《向僵尸开炮》）。战车固定在屏幕底部中央（不横移），怪物自屏幕上方刷出（中间密、向两侧递减）。车载武器是全游戏唯一攻击来源（无枪械、无角色攻击），共两件，全程手动、无自动模式：

- **车载机枪（持续输出）**：锥形射界，玩家点按场景方向，机枪转向该方向开火；射速高、可穿透 1~2 个目标。
- **火箭筒（爆发输出）**：从火箭筒按钮**拖动**到场景区域松手，火箭弹飞落该点造成范围伤害；装填长，单场使用 3~5 发（升级提升伤害、范围与单场上限）。

**弹药经济（演出与结算分离）**：战斗中画面打出的弹数不进任何账本；结算只认两条规则——

- 机枪：每场战斗固定扣一次弹药，量随区域等级升高（关卡等级越高消耗越高，收益也越高）。
- 火箭弹：出发整备时按发携带，每发折算弹药资源（与机枪弹同账）；未携带时火箭筒不可用，机枪不受影响。

机枪与火箭筒的升级线、各区域单场弹药消耗表见 PENDING（D13）。

## 8. 主角与乘员

**主角**：开局多选一（清单见 PENDING D11）。每个主角带一个天赋：**去对应区域探索时，该类物资掉落大幅增加**，外加一个专属身份特长——主角设计为「资源策略路线选择」：食物系主角加速多招人、药品系主角强化战士（如补剂制作费用降低）。主角默认司机、人车合一：永远在车上，占驾驶位，不计入载客量与人数乘数；正常消耗食物、参与健康结算。

**强化补剂「人类补完の剂」**：工作台配方，3 药品 + 2 食物 → 1 份，为一名角色**永久提升健康值上限 +50，同时恢复当前健康 +50**。限用 2 次，上限封顶 200。作用：①给药品一个主动消耗出口（避免熟练玩家药品囤积无通路）；②把健康度 >100 的获取率 ×2 门槛变成可用药品投资达成的目标——药品的基础资源属性由此成立，药品系主角不会边缘化。

**NPC 乘员**：属性人人一致，无职业、无装备栏。每人只有**健康度**（药品恢复，补剂提升上限）。价值 = 人数：乘员越多，探索物资乘数与车辆攻击乘数越高。招募流程：探索中**首遇** NPC 接下其任务 → 返回仓库在**任务板**交付（不需要在探索中再遇同一人）→ 达成后即可在任务板邀请入队。首遇在探索、交付与招募在仓库——省去「再相遇」的系统复杂度。每个区域 2 个 NPC，每个 NPC 两种入队条件：**20 件对应资源 或 40 食物**。食物流优势：食物 ×2 → 攒 40 食物远快于其他流派攒 20 对应资源。

**健康与收益挂钩**：探索收益倍率与攻击力均按队伍总体健康度阶梯计算——健康度 ≤50 → 获取率 100%（无加成）；>50 → 获取率 100%；>100 → 获取率 200%。两档制，50 和 100 是绝对值不是百分比。

## 9. 地图与区域探索

**三级区域架构**：平面大地图上 N 个区域（数量多于旧骨架的 5~6 个），每个区域内部再分**三级子区域**（难度与收益阶梯递进）。地图交互流程：

1. 大地图（平面，仓库在一角、市中心在中央）。点**仓库**进入仓库界面（升级/制作/整备，UI 设计见 PENDING D18）；点**区域**弹出次级区域选择（三级子区域）。
2. 选定子区域后，播放**大地图出发动画**：战车从仓库驶向该区域。
3. 进入**横轴区域场景**（类归家异途）：连续事件节点，逐个触发——

- **搜刮点**：汇报式结算（「在 XX 区域发现 N 药品、N 燃油、N 食物、某区域地图 1/3、某物品制作图纸」），弹出背包系统拾取装舱。
- **NPC 对话**：任务式交易（「我有一份 XX 物品，我需要 N 药品、N 食物或某个合成物品」），首遇接任务；交付在仓库任务板完成（§8）。
- **战斗（可选）**：怪物关卡可战可绕——前置弹框明示本场机枪扣弹量、怪物数量、火箭弹现有量与**怪物掉落收益**，玩家确认进入竖版战斗（§7），或选择绕行放弃掉落继续前进。弹药不足时选择战斗则按战败结算（损失见 D20），不回档——弹药不足的出路是「绕」，不是「退」。怪物掉落显著高于同级搜刮点（引导积极战斗，弹药流的收益主场）。
- **战斗失败**：载具耐久 **-50**，本场无掉落。玩家可立即选择返程，或继续探索（再战再 -50）。战车耐久归零 = 游戏结束。
- **boss 战（区域尾节点，不可绕）**：弹药不足强开 boss = 重罚结算——仓库耐久、战车耐久、全员健康各 -50（数值见 D22）。**终局 boss（基站修复完成后的最终守家战）弹药不足 = 直接 game over**——终局无路可绕，进终局前必须备足弹药。

- 区域默认**锁定**，通过**情报解锁**（NPC 任务奖励、探索掉落的区域地图碎片如「某区域地图 1/3」）——地图不是开局明牌，揭示感是长线新鲜感的来源。
- 各区域掉落倾向不同（医院区多药品、工厂区多材料……），缺什么去哪；凑齐升级材料需要探索多个区域。
- 单区域 = 横轴连续 **10 个事件节点**，构成默认：4 个搜刮点 + 1~2 个 NPC + 2~3 个怪物关卡（可选战或绕行）+ 余量随机事件，顺序随机。子区域等级越高收益越高、怪物越强、机枪扣弹越多（扣弹阶梯见 D13）。区域尾节点为 boss 战（固定 N 局，D17；boss 战为该子区域的收口关卡，不可绕——见 D17 拍板）。
- **图纸双通道**：深区探索随机掉落 + NPC 任务定向换取。基站设备图纸走同一通道。

## 10. 守家战（波次）

每隔 N 天怪物找上门（间隔与强度曲线见 PENDING D5）。**波次明牌**：下一波强度提前一天预告，玩家能做预算——没有突然袭击。

守家战与探索战共用同一套实时战斗操作（第 7 节），唯一差异：**战车前方多一道围墙（仓库耐久）**。伤害管道串联：**仓库耐久 → 战车耐久 → 全员健康**；探索战没有围墙，从战车耐久起算。三层全部扣光 = 本局失败，重开。不做漏怪判定——怪物伤害直接沿管道结算，少一层计算系统。

仓库耐久修复成本为战车的 0.5 倍（墙比车好修），修复比例统一为 1 材料 = 25 耐久。

危险度即波强度刻度：随天数与事件推升，决定下一波规模，守家表现反作用于它；爬升至平台值后封顶（休闲玩家可以慢慢修基站，「慢」必须可行）。

## 11. 胜利与失败

- **胜利**：收集齐基站设备图纸 → 工作台制作替换设备 → 修复市中心通信基站 → 求救信号发出 → **终局守家战**（最猛一波，弹药不足即 game over）→ 抵抗军抵达 = 胜利结局：人类抵抗部队获得战斗胜利，并找到了这个还在抵抗的庇护所。
- **失败**：全员健康归零。失败就重开，好好做人，别再当菜鸟。
- 首版单一胜负结局，不做多结局分支。

## 12. 序章与首局教学

控制在约 15 秒内开始操作：三选一选主角（天赋当场展示）→ 车辆自动驶向仓库 → 路上出现若干可拾取物资与一次装不下的取舍 → 抵达仓库，带回内容即开局资源。不制作长过场。

## 13. 广告与付费底线

（不变）广告只能提供额外选择，不能消灭载重和生存取舍。不放横幅、开屏和强制插屏；只允许玩家主动触发的低频激励视频；广告失败不阻断游戏；不用「全物资翻倍」破坏核心规则；不通过提高油耗、制造必死局贩卖解药。首版候选入口仍是无线电侦察与事故紧急救援，核心循环成立后再验证。

## 14. 设计纪律

从 GDD 对话沉淀的硬约束，评审时按此执行：

1. **决策不超前于信息**：不让玩家在信息不足时做高频决策（迷雾疲劳的教训）；波次明牌、账目可预算。
2. **合成 ≤ 1 跳**：战利品即零件，不做中间品树。
3. **牌面即全部真相**：规则语义写在界面上，不藏在判例里（游戏王的教训）。
4. **单一攻击管道**：攻击来源只有车载武器一套（机枪+火箭筒），不新增平行武器系统；演出弹数与结算账目分离。
5. **新要素先问能否挂在现有五资源上**，挂不上就不做。

## 15. 当前进度与旧模型的关系

六切片（竖屏拖拽/货舱占格/地图卷轴/节点拾取/十日循环/道路事件）已验证的手感资产**全部复用**：货舱拖拽与占格、横轴卷轴演出、事件面板与结算框架、五资源账目。

与旧模型的冲突项，自下阶段起参数化改造：十日循环 → 长局与波次（`GAME_DAYS` 参数化）、六地点单线 → 区域制与解锁、职业数据 → 主角天赋制、幸存者占舱 → 载客量制。存档 schema 将随首个改造切片升级版本。最新进度见 [README.md](../README.md)。

## 16. 停车场：首版明确不做

- PC 版及跨平台界面。
- 开放世界连续大地图、自由走格子驱雾（我们做的是平面区域地图 + 横轴场景入口）。
- 手动回合制、战斗 AI、怪物寻路（战斗为竖版定点实时射击，怪物沿直线下行）。
- 载具横移、驾驶操作（战车固定底部中央，只控武器朝向）。
- 自由建造、生产链、每日手动收菜。
- 角色装备栏、词条稀有度、技能树、NPC 职业属性差异。
- 多车辆编队、多武器系统。
- 联机、排行榜、社交。
- 物理引擎、3D、骨骼动画、重型粒子。
- 付费系统及广告变现调优。
