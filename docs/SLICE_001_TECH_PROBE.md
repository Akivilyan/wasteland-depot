# 切片 001：后备箱技术探路版

## 目标

验证 Cocos Creator 3.8.8 到微信小游戏的最小开发闭环，以及竖屏拖拽和本地存档能否作为后续玩法的可靠基础。

本切片不验证完整游戏是否好玩，也不包含地图、外出、基地建设、战斗或广告。

## 已实现

- 750 × 1334 竖屏设计分辨率。
- 三格车辆后备箱。
- 燃油、食物、药品三张可拖拽物资卡。
- 物资放入空槽、跨槽移动和占用槽替换。
- 物资拖出后备箱。
- 清空后备箱按钮。
- 浏览器 `localStorage`、微信同步存储和内存回退适配。
- 规则层与 Cocos、微信 API 隔离。
- Web Mobile 与微信小游戏脚本化构建。
- 保留 `Animation` 与 `Tween` 作为轻量交互动画基础。
- 裁剪未使用的 Spine、DragonBones、Box2D、音视频等引擎模块。

## 财哥人工测试

在微信开发者工具中完成以下测试：

1. 首屏为竖屏，标题、三格后备箱、三张物资卡和“清空后备箱”均完整可见，没有性能统计层遮挡。
2. 分别把燃油、食物、药品拖进三个槽位，卡片应吸附到槽位中心。
3. 把已经入箱的卡片拖到另一个空槽，物资只能出现一次，原槽应清空。
4. 把一张卡片拖到已有物资的槽位，新卡片应占据该槽，原卡片回到底部。
5. 把箱内卡片拖回箱外，卡片应回到底部并显示已保存提示。
6. 任意摆放后重新编译或关闭再打开模拟器，布局应从存档恢复。
7. 点击“清空后备箱”后重新打开，三个槽位仍应为空。
8. 切换至少两种常见竖屏设备，确认标题、后备箱、底部卡片、按钮和状态文字没有裁切或重叠。
9. 打开控制台，确认没有红色错误；开发者工具或基础库自身的黄色兼容性提示另行记录。
