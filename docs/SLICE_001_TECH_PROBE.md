# SLICE_001：后备箱技术探路版

> 状态：自动验证 ✅ 通过；人工验收 ✅ 通过（技术探针闭环，非玩法手感）。
> 本切片验证「Cocos → 微信小游戏」最小开发链路，不验证游戏好不好玩。

## 验证的问题

1. Cocos Creator 3.8.8 竖屏触摸/拖拽在微信小游戏里是否可靠。
2. 物资进槽、移槽、换槽、拖出的规则是否可测试。
3. Web 与微信能否共用同一份规则、接不同存储适配。
4. Cocos 构建、微信开发者工具、真机链路是否畅通。

## 范围（只做这些）

- 750 × 1334 竖屏设计分辨率。
- 三格车辆后备箱 + 燃油/食物/药品三张可拖拽物资卡。
- 物资放入空槽、跨槽移动、占用槽替换、拖出箱外、一键清空。
- 浏览器 `localStorage` / 微信同步存储 / 内存回退，三端同一适配接口。
- 规则层与 Cocos、微信 API 隔离。
- 裁剪未使用的 Spine、DragonBones、Box2D、音视频等引擎模块，保留 `Animation`/`Tween`。

## 不做（明确排除）

地图、外出、基地建设、战斗、广告——都留给后续切片。

- Web Mobile 与微信小游戏脚本化构建：通过。
