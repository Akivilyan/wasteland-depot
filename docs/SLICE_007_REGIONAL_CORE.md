# SLICE_007 核心层区域制改造

> 目标：把 GAME_DESIGN v9 的区域制长局模型落成纯规则层（core），旧十日模型的继任者。
> 本切片纯新增（旧 core 五文件保留供旧场景编译，表现层切换完成后删除）。

## 范围

- 新增 9 个 core 文件：`config.ts`（机制常数唯一出处）、`regions.ts`（六区域×三层/NPC 名册/节点生成/掉落）、`hero.ts`（四流派）、`events.ts`（事件池 12 个起步）、`hold.ts`（货舱槽位模型：每格类型上限+堆叠，取代形状占格）、`combat.ts`（伤害管道 围墙→车→人/波次构成/武器档案）、`boss.ts`（首杀掉落表：地图+四零件绑定）、`state.ts`（GameState v2+存档）、`run.ts`（全部命令引擎）。
- 天数模型：去程 1 天（不扣）→ 每节点 1 天（扣当日油/食）→ 返程 1 天（不扣）；波次日历（20/40/60…日结）内建于每次 day+1。
- 保底必遇：boss=该层累计第 10 节点（计数跨出发累计、boss 未杀恒占位）；NPC=全局普通节点 10/15/20/每 5。
- 存档：`wasteland-depot.run.v2`（已登记 ALL_SAVE_KEYS）；Expedition 内嵌状态、中断即存档。
- 旧模型（sim/route/loot/game/constants v1）不动、不删——表现层切到 run.ts 后（SLICE_008/009）再清理。

## 关键拍板（丧彪定，ADR-023 授权）

- 断粮语义按「全天份」：没吃到 2 食物的人当天 -2 血（不按餐拆分，整数口算）。
- 出行成员=全部非濒死乘员自动随队（无逐次选人 UI）；座位=成员总数上限（招募时校验）。
- NPC 保底计数只统计普通节点（scavenge/event/monster），boss/NPC 节点不计入，避免保底自我干扰。
- 终局倒计时归零：在仓库→立即拦下出发、待战；在途→顺延至返仓当刻。
- 守家战缺席=清仓库五资源+掉墙，货舱物资照常带回（清的是当时刻库存）。
- 队长折扣 -25% 适用于全部材料升级（科技四线+两个 + 号按钮），向上取整。
