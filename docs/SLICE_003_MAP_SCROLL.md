# SLICE_003：地图骨架 + 行车卷轴演出

> 状态：已实现并通过验证（2026-09-02）。规则层 54 测试全绿；Web Mobile 与微信构建均通过；
> 微信模拟器经 CDP 驱动走完全链路（选点 → 出发 → 卷轴 → 抵达 → 返程 → 回地图），
> phase 迁移与存档正确，无游戏代码报错。手感待人工验收。

## 验证中发现的实现修正

- `UIOpacity` 上没有 `stopAllActions`（那是 `Node` 的方法），停呼吸动画须用
  `Tween.stopAllByTarget(op)`。真机 TypeError 由 CDP 驱动回归抓到后修复。

## 本切片验证的问题

1. **地图骨架手感**：竖向单线公路 + 节点牌点选是否够清楚、够快。
2. **行车演出手感**：横轴卷轴（三层视差：天空 / 废墟剪影 / 路面）+ 跳过按钮，
   时长 4.2s 是否可接受。
3. **结构可行性**：地图 ↔ 演出 ↔ 节点面板 的 phase 切换能否干净复用现有 UI 风格。

## 范围（只做这些）

- 规则层 `core/route.ts`：一条路线（仓库 + 5 地点，里程递增）、油耗换算
  （每 10km 1 油，向上取整）、depart/arrive/departReturn/backToMap 相位机、存档编解码。
- 表现层 `presentation/TravelScene.ts`：
  - 地图：竖向公路骨架，节点牌显示 `名称 / km / 油耗`，点选呼吸高亮环，出发按钮。
  - 行车：全屏卷轴演出，中景 1x、近景 1.35x 视差滚动，路牌掠过；可跳过。
  - 抵达：简易面板占位（节点交互留待下一切片接入货舱），返程按钮触发回程演出。
- 存档：`wasteland-depot.trip.v1`，非法数据回退初始态。

## 不做（明确排除）

- 节点交互 / 搜集 / 事件（下一切片：抵达节点 → 接货舱取舍）。
- 迷雾、多路线、branch 路径、地图缩放拖动。
- 素材图（全部 Graphics 程序化绘制，验证手感后美术再替换）。
- 燃油与真实 GameState（sim.ts）的联动：本切片用 `setFuel()` 注入，
  接入十日循环时替换为真实库存。

## 验收

- `npm test`：route.ts 7 个新用例 + 原有 47 个全绿。
- Web Mobile 构建可打开，地图 → 出发 → 卷轴 → 抵达 → 返程 → 回地图 全链路可走。
- 微信模拟器同样可走全链路（MCP CDP 验证 phase 迁移与报错），无游戏代码报错。
